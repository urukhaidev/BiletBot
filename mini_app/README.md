# BiletBot Mini App

Отдельный интерфейс и FastAPI-сервис, использующий `biletbot` как поисковое ядро. Адрес: https://biletbot.ru/mini-app.

## Файлы

- `server.py` — HTTP API, фоновые задания поиска, профиль и алерты.
- `auth.py` — проверка Telegram `initData` по HMAC, срока сессии и пользователя.
- `static/` — адаптивный интерфейс, Telegram WebApp SDK, нижняя liquid-glass навигация.
- `deploy/` — пример systemd-сервиса и Nginx-конфигурации.

## Запуск

```bash
pip install -e '.[test]'
pip install -r mini_app/requirements.txt
python -m uvicorn mini_app.server:app --host 127.0.0.1 --port 8078
```

Используется `.env` бота и та же SQLite-база. Для API нужен один worker: фоновые задания находятся в памяти. Поиски сохраняются в SQLite; после перезапуска сервиса незавершённый поиск следует повторить.

В браузере форма доступна для просмотра. Поиск, профиль и подписки требуют запуска из Telegram — ID из неподписанных параметров не принимаются. Кнопка меню бота ведёт на HTTPS URL мини-аппа. Дополнительно в BotFather можно настроить Main Mini App на этот URL для кнопки в профиле бота.

Форма поддерживает город отправления и назначения с подсказками, до 6 месяцев за один поиск, точную дату вылета/возврата, диапазон вылета, OW/RT/оба типа, длительность поездки, прямые рейсы и багаж. Для каждого выбранного месяца результаты приходят отдельным Rich Message в бот, а в мини-аппе отображаются общей выдачей. Подписки создаются существующими кнопками бота; в мини-аппе можно просматривать и останавливать их. Профиль показывает количество сохранённых поисков по условиям и последние 10 записей.

Личные данные выводятся с экранированием. Ключи API остаются на сервере. Статические файлы не содержат токенов.

Manrope в `static/Manrope.ttf` распространяется по SIL Open Font License; текст лицензии находится в `biletbot/fonts/OFL.txt`.
